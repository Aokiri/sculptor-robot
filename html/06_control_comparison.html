Control comparison¶

The Panda carves the pawn model with the plan of notebook 05: the same moves, and the table turning between the sides with its motion profile and PID. Here we add noise on the joints and compare open and closed loop, each with the posture task on and off. Every run follows the same clock.

The runs are computed by experiments/control_comparison.py and saved as two tables in results/06_control_comparison/, one row per run (runs.csv) and the arrival errors of one seed (drift.csv). This notebook only reads them.

1. From joint command to contact¶

The STL, 3 cm voxels, initial Panda configuration, IK seed 0, target order and the table with its motion profile and PID come from notebook 05. Its noise-free, posture-on controller supplies the duration of every cut, withdrawal, joint transfer and approach. All four conditions therefore get the same time to reach each target.

  • Closed loop. At each active step, RRMC recomputes the joint velocity from the actual joint angles and tip pose. Joint-space transfers use proportional feedback on the remaining joint error.
  • Open loop. For each posture setting, a noise-free run records those joint velocities before the joint stops are applied. The arm replays the velocities from its actual position, including any accumulated error.
  • Posture. The primary gain is 3 in every run. With posture on, the existing null-space term pulls towards the IK reference with gain 2. With posture off, its gain is zero.

For an active sample of duration $\Delta t=0.05$ s, the simulator applies $q_{k+1}=\mathrm{clip}(q_k+\dot q_k\Delta t+w_k,\,q_{\min},q_{\max})$. Each of the seven components of $w_k$ is an independent normal joint displacement with standard deviation $\sigma$ radians per step. A common seed gives all four conditions the same sequence of displacements. The table turns along its motion profile, with its PID, while the arm holds the last joint configuration.

At every sample, including setup, forward kinematics gives the tip position. The actual table angle maps it into the block frame. The first time the point lies inside a present cube, the cube is removed. This includes the statue, incidental marble and contact during withdrawal or table rotation. A missed target stays until a later contact. A tip can cross material between two samples without being observed. The result measures point contact at 50 ms intervals. Chisel force and collisions of the body or links would require separate measurements.

RRMC and its null-space term are the ones of src/sculptor/controller.py, and the open loop replays the velocities of a noise-free run (CarvingPlan in src/sculptor/carving.py).

2. Arrivals¶

The tool begins at the first cube. We report that setup point separately. For each subsequent approach or cut, attempt_end_step records the last allotted step, whether or not the tip reaches the cube. Arrival error is the Euclidean tip-to-centre distance at that step. The arrival RMSE gives all 1,595 moves equal weight. The 1 mm count uses the same endpoints. Removal can happen sooner because the voxel extends 15 mm from its centre on each axis.

Notebook 05 also logged the distance on all samples with a target, including withdrawals, so that error is dominated by the repositions. The table of section 3 keeps it as the all-sample RMSE.

The campaign uses $\sigma=0$, 0.001 and 0.005 rad per active step and seeds 0 through 4. After the zero-noise check, twelve pilot runs covered all four conditions at 0.001 rad and seeds 0 through 2. Each pilot counts once in the final 60. At zero noise, the five seeds test repeatability.

Each row below is a mean across five seeds. Damage uses the original 208 statue cubes as its denominator. colors = ["#9b5418", "#176b75", "#9b5418", "#176b75"]
ticks = ["Open\noff", "Open\non", "Closed\noff", "Closed\non"]


def plot_seeds(metrics: list[tuple[str, str]], title: str) -> None:
    """Show five individual seeds and their mean and sample SD for each condition."""
    fig, axes = plt.subplots(len(metrics), len(noises), figsize=(11.6, 6.5), layout="constrained")
    for row, (field, unit) in enumerate(metrics):
        for column, noise in enumerate(noises):
            ax = axes[row, column]
            for x, label in enumerate(conditions):
                selected = (done.noise_std == noise) & (done["control / posture"] == label)
                group = done.loc[selected].sort_values("seed")
                values = group[field].to_numpy()
                offsets = (group.seed.to_numpy() - 2) * 0.065
                ax.scatter(x + offsets, values, s=22, color=colors[x], alpha=0.72, zorder=3)
                mean = values.mean()
                spread = values.std(ddof=1)
                ax.errorbar(x, mean, yerr=spread, fmt="D", markersize=4,
                            color="#25262b", linewidth=1.3, capsize=4, zorder=4)
            ax.set_xticks(range(4), ticks)
            ax.set_xlim(-0.45, 3.45)
            ax.set_axisbelow(True)
            ax.grid(axis="y", color="#dedede", linewidth=0.7)
            ax.spines[["top", "right"]].set_visible(False)
            if column == 0:
                ax.set_ylabel(unit)
            if row == 0:
                ax.set_title(f"Noise {noise:g} rad/step")
            if field == "arrival_rmse_mm":
                ax.set_yscale("log")
            else:
                ax.yaxis.set_major_locator(MaxNLocator(nbins=5, integer=True))
                low, high = ax.get_ylim()
                low, high = min(0, low), max(1, high)
                pad = 0.04 * (high - low)
                ax.set_ylim(low - pad, high + pad)
        if field == "arrival_rmse_mm":
            low, high = axes[row, 0].get_ylim()
            for ax in axes[row, 1:]:
                left, right = ax.get_ylim()
                low, high = min(low, left), max(high, right)
            for ax in axes[row]:
                ax.set_ylim(low / 1.2, high * 1.12)
    fig.suptitle(title)
    plt.show()

The comparisons cover one STL and five paired disturbance sequences per nonzero noise level. They answer what the tip removes in the nominal time budget. A controller allowed extra settling time would answer a different question.

Reproduce the figures¶

Run all cells from a fresh Python kernel. The two CSVs above are sufficient. To regenerate the trajectories and tables, run uv run python -m experiments.control_comparison --jobs 4 from the repository root. The experiment saves one local NPZ per run. See the experiment instructions and notebook 05, section 1.3 for the P, I and D terms during a table turn.

Summary¶

The next notebooks reuse the comparison of the carving under noise (CarvingPlan and run in src/sculptor/carving.py, experiments/control_comparison.py) and its two tables in results/06_control_comparison/.

Without noise, open and closed loop carve the same: no statue cube removed, and all 1595 moves end within 1 mm with the posture task (section 3). With 0.001 rad per step, closed loop keeps the whole statue in every run, while open loop removes 28.40 statue cubes on average with the posture off and 18.80 with it on, and leaves most of the marble (section 3). With 0.005 rad per step both lose part of the statue; open loop loses less only because it barely carves. The posture task lowers the arrival error of the closed loop, from 3.70 to 2.58 mm at 0.001 rad (section 3), and along the carving order the open-loop error grows while the closed-loop error stays small (section 4).
